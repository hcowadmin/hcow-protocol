Check a round. Without trusting us.

Paste the receipt from any round. This page recomputes the record hash, checks the seed that was published before the round was played, and compares the result against the anchor stored on BNB Chain.

Everything runs in your browser. No library is loaded from anywhere. The only network request is a read call to a public BNB Chain node, and you can point it at your own node below. The full record format is published so you can write your own checker instead of using this one.

Settings and record format

A record is hashed as keccak256(domain + canonical) where canonical is the nine fields of that record kind, in this exact order, joined with tab characters and ending in a newline. Backslash, tab and newline inside a value are escaped as \\\\, \\t, \\n.

skill    HCOWs1|   gameId  roundId  playerRef  mode  level  score  durationMs  outcome  endedAt
seeded   HCOWv1|   gameId  roundId  playerRef  serverSeedHash  serverSeed  clientSeed  nonce  outcome  timestamp

Leaves are combined with sorted pair keccak hashing. A proof is the list of sibling hashes from the leaf to the root, with no direction bits.
